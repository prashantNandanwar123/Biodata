# Marriage Biodata Website (React + Vite + Tailwind)

## Run
    npm install
    npm run dev        # open http://localhost:5173
    npm run build      # production build in /dist (deploy to Netlify / Vercel / GitHub Pages)

## Edit
- All details: `src/data/biodata.js` (empty fields are hidden automatically)
- Photos: replace `public/images/profile.jpeg` and `gallery-1.jpeg` ... `gallery-3.jpeg`
- Downloadable PDF: `public/biodata.pdf`
